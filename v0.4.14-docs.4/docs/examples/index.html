Examples

Copyable, schema-validated configurations, some runnable on your machine.

Two kinds of example:

  • Runnable — a packaged demo under deploy/local/ in the source repository starts the whole stack on *.localhost (no domain, no external account). ./run.sh prints the URLs.
  • Configuration pattern — a realistic routes.json for a setup that needs an external service (Keycloak, Google, GitHub). It is schema-validated; adapt it to your infrastructure.

The runnable demos live in the source repository under deploy/local/. They need the Gate One binaries (download a release and verify the checksums) and, for the OIDC demos, Docker Compose.

Production deployment

A starting point with Traefik, TLS, Gate One and cladone-auth, ready to copy to a VPS, is deploy/vps/.

Getting started

A local demo with the embedded development identity provider.

Direct OIDC with one IdP

Point Gate One straight at a single OIDC issuer, with no federation and no IAM.

Multi-app SSO

Add a second application to an existing login session.

Cross-domain SSO

One IdP login across app-a.com and app-b.fr, with one provider per domain.

Keycloak with Google

Federate Google in Keycloak, then point Gate One at one Keycloak issuer.

Embedded IAM

Federate IdPs in cladone-auth, map claims and assign user grants.

High Availability

Balance load across several Gate One replicas with shared session and revocation state.

APIs and MCP

A browser provider, a JWT provider and an MCP protected resource.

Own account panel

Replace the built-in user badge with a burger side panel owned by the application.

IAM + IdP bridge

An http-bridge provider returning identity and IAM facts while Gate One keeps policy enforcement.

MCP tools

A REST-derived MCP service, a proxied MCP server and an aggregating set, with delegated credentials.

Injectable UX

Badge, gating, injection bundle, 403 banner and CSP.

Enhance a proxied site

Proxy an external site through Gate One and inject a userscript into every HTML page.

Usage plugin

A signed audit plugin, a trust store and a durable WAL.

Turnstile protection

A public form and a whole-page gate protected by Cloudflare Turnstile.
