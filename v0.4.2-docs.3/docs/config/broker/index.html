Broker configuration

Generated from schemas/broker.schema.json by scripts/gen-config-docs. Do not edit this page: edit the schema or the generator.

The optional cladone-auth broker configuration. Secrets are read from the environment; a *Env field names the variable.

Fields

FieldTypeRequiredDescription

publicUrl

string

yes

External origin of the broker, without a trailing slash (for example https://auth.example.com).

listen

string

no

Default listen address for cmd/cladone-auth (for example :8081).

sessionCookieName

string

no

Broker SSO cookie shared by all applications in one browser. Default cladone_broker_sid.

tenants

array of object

yes

Isolated issuers. Each tenant has its own key, client, upstream identity providers and policy.

redis

object

no

Shared store for flows, codes, refresh tokens and the revocation keyspace read by Gate One. Absent = in-memory store, single instance and tests only.

smtp

object

no

Outbound mail relay for local-account verification emails.

no

Environment variable holding the Gate One client secret.

string

Published keys, oldest first, newest active. Used to rotate tokens without invalidating old ones.

Environment variable gating POST /register (server-to-server registration).

mappings

array of object

no

Ordered mapping rules translating upstream claims into broker roles/scopes/claims. Evaluated on every federated login; results are not persisted on the user. The legacy groupRoles block remains supported for the groups claim.
