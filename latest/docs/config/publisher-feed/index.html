Publisher feed

Generated from schemas/publisher-feed.schema.json by scripts/gen-config-docs. Do not edit this page: edit the schema or the generator.

The signed document referenced by publisherFeed.file: compatible Gate One versions, external components and plugins, with their version-compatibility rules and revocation status.
