| no

| [[field-routes-upstream-rewriteCookies]] `rewriteCookies`
| <<config-routes-upstream-rewriteCookies,object>>
| no

Active: a Domain targeting the origin host (equal or parent) is rewritten to the public host in "rewrite" mode (the sharing scope — host + subdomains — is transposed as-is), or the attribute is removed in "strip" mode (host-only on the public host). | [[field-routes-upstream-stripCookies]] `stripCookies`

| no

| [[field-routes-upstream-browserCache]] `browserCache`

| no
| HTTP-cache orientation to the BROWSER for assets the origin serves with no Cache-Control (and no Last-Modified either: without these two headers the browser has no heuristic cache — every re-view re-fetches or revalidates each asset, one full round-trip each). Only 200 responses of content-type image/*, Cache-Control absent only: the origin's own declarations pass untouched. Sent as "private, max-age=…" — private: resources under authentication stay out of any shared cache; the origin's ETag remains for revalidation after expiry. [[config-routes-upstream-rewriteCookies]]
===== routes.upstream.rewriteCookies

Translation of the Set-Cookie set by the origin: a Domain attribute targeting its own namespace ("Domain=original…domain.dev") would be rejected by the browser from the public host — the cookie would be silently lost. Active: a Domain targeting the origin host (equal or parent) is rewritten to the public host in "rewrite" mode (the sharing scope — host + subdomains — is transposed as-is), or the attribute is removed in "strip" mode (host-only on the public host). Other cookies pass intact (surgery of the Domain attribute only: Path/Secure/HttpOnly/SameSite/Expires come out byte-exact). Auth protection: an origin Set-Cookie bearing a name reserved for the gateway session (access_token, refresh_token, id_token, session) is removed with a warning — set on the same public host, it would overwrite the session cookies. Default: absent (no cookie rewriting).

[cols="2,2,1,5",options="header"]
|===
| Field | Type | Required | Description

| [[field-routes-upstream-rewriteCookies-domain]] `domain`
| string (one of: `rewrite`, `strip`)
| yes
| "rewrite" (recommended) = Domain transposed to the public host; "strip" = Domain attribute removed.

[[config-routes-upstream-browserCache]]

HTTP-cache orientation to the BROWSER for assets the origin serves with no Cache-Control (and no Last-Modified either: without these two headers the browser has no heuristic cache — every re-view re-fetches or revalidates each asset, one full round-trip each). [[config-routes-csp]]
==== routes.csp

Content-Security-Policy emitted (or amended) by the gateway — the only component able to generate a per-response nonce and write it into the HTML it already rewrites (guard, PWA, custom injections). By default the origin's policy is NEVER removed or weakened: the gateway's policy is added as a SECOND header (browsers enforce all of them, so the effective rule is the strictest) and the hashes of the gateway's own injected script and guard stylesheet are APPENDED to the origin's script-src / style-src (script-src-elem > script-src > default-src, style-src-elem > style-src > default-src). Set own=true to remove the origin policy explicitly and let the gateway own it (opt-in, logged, requires mode nonce/hash and reportOnly=false). Applied to HTML responses only.

[cols="2,2,1,5",options="header"]
|===
| Field | Type | Required | Description

| [[field-routes-csp-mode]] `mode`
| string (one of: `off`, `merge`, `hash`, `nonce`)
| yes
| "off" = nothing (the origin's policy passes as-is); "merge" = keep the origin policy and only add the hashes of the gateway's injected scripts (no policy of our own); "hash" = emit our policy with those hashes, no body rewrite; "nonce" = emit our policy with a per-response nonce and stamp the HTML in STREAMING mode (O(1) memory, upstream forced to gzip so the body is plain text).

| [[field-routes-csp-reportOnly]] `reportOnly`
| boolean
| no
| Emit Content-Security-Policy-Report-Only instead of the enforcing header (progressive rollout: violations are collected, nothing is blocked). Requires mode nonce or hash.

| [[field-routes-csp-own]] `own`
| boolean
| no
| The gateway OWNS the policy: the origin's enforced and report-only CSP headers are removed before ours is emitted. Opt-in and logged (never silent). Requires mode nonce or hash and reportOnly=false: removing the origin's enforcing policy to replace it with a report-only one would remove protection without enforcing anything. Use only for a site you control/accept, with a complete policy.

| [[field-routes-csp-reportTo]] `reportTo`
| string
| no
| Local path served by the gateway collecting the violations (report-uri). Default: /__gate-one_csp/report. Bounded ring buffer (256 entries), 16 KiB body limit, 50 reports/second, never authenticated. Pattern: `^/[^\s?#]*$`.

| [[field-routes-csp-stampScripts]] `stampScripts`
| string (one of: `inline`, `all`)
| no
| "inline" (default) = only <script> tags WITHOUT src receive the nonce (external scripts stay governed by the host allow-list); "all" = every <script> tag. Nonce mode only. A tag that already carries a nonce is never rewritten.

[[config-routes-uiGate]]

UI gating rule by config — for fronts whose markup cannot be modified (if you control the HTML, prefer the data-gtw-* attributes). The selected element is visible only if the session satisfies the conditions (OR on roles, OR on scopes, AND on claims). PRECEDENCE: an element carrying at least one data-gtw-* attribute ignores uiGate rules; several rules on a same element combine with AND; invalid selector = rule ignored.

[cols="2,2,1,5",options="header"]
|===
| Field | Type | Required | Description

| [[field-routes-uiGate-selector]] `selector`
| string
| yes
| CSS selector (querySelectorAll) of the targeted elements.

| [[field-routes-uiGate-roles]] `roles`
| array of string
| no
| Visible if AT LEAST ONE of these roles is held.

| [[field-routes-uiGate-scopes]] `scopes`
| array of string
| no
| Visible if AT LEAST ONE of these scopes is granted.

| [[field-routes-uiGate-claims]] `claims`
| object
| no
| All must match ("*" = presence).

| [[field-routes-uiGate-auth]] `auth`
| string (one of: `after`, `before`)
| no
| Turns the selected elements into login triggers: after = native action preserved + invitation tab; before = click neutralized + direct tab. Activation only: deactivations (unchecking, closing details, reset, returning a value control to its OFF value) are never gated. | [[field-routes-uiGate-hidden]] `hidden`
