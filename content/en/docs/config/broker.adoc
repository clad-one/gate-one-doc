= Broker configuration

The optional `cladone-auth` broker configuration. Secrets are read from the environment; a `*Env` field names the variable.

[[config-tenants-google]]
==== tenants.google

Upstream OIDC identity provider configuration. The google key defaults to the Google issuer; other keys require issuer, clientId/Env and clientSecret/Env.

[cols="2,2,1,5",options="header"]
|===
| Field | Type | Required | Description

| [[field-tenants-google-issuer]] `issuer`
| string
| no
| Upstream OIDC issuer. Default https://accounts.google.com for the google upstream; required for other upstreams.

| [[field-tenants-google-clientId]] `clientId`
| string
| no
| Upstream OIDC client id. Prefer clientIdEnv.

| [[field-tenants-google-clientIdEnv]] `clientIdEnv`
| string
| no
| Environment variable holding the upstream client id.

| [[field-tenants-google-clientSecret]] `clientSecret`
| string
| no
| Inline upstream client secret. Prefer clientSecretEnv. Write-only; prefer the `*Env` form.

| [[field-tenants-google-clientSecretEnv]] `clientSecretEnv`
| string
| no
| Environment variable holding the upstream client secret.

| [[field-tenants-google-prompt]] `prompt`
| string
| no
| Forwarded to the upstream authorize endpoint (for example select_account).

| [[field-tenants-google-hostedDomain]] `hostedDomain`
| string
| no
| Google Workspace hosted domain (hd) restriction.

| [[field-tenants-google-scopes]] `scopes`
| array of string
| no
| Upstream scopes. Default openid, profile, email.

| [[field-tenants-google-displayName]] `displayName`
| string
| no
| Label shown on the identity provider chooser. Default: the upstream key.

| [[field-tenants-google-optional]] `optional`
| boolean
| no
| Skip this upstream when its client id/secret environment variables are empty, instead of refusing startup.

|===
