= Plugin manifest
:toc: left
:toclevels: 3
:icons: font

Generated from `schemas/plugin-manifest.schema.json` by `scripts/gen-config-docs`. Do not edit this page: edit the schema or the generator.

The signed manifest shipped with an out-of-process plugin. The operator references it from `usage.plugins[].manifest`; the trust store decides whether the signer and the artefact are trusted.

|===
| Field | Type | Required | Description

| [[field-schemaVersion]] `schemaVersion`
| integer (fixed: `1`)

| [[field-kind]] `kind`
| string (one of: `extension`, `auth`)
| yes
| Plugin kind. auth requires the trust store to allow auth modules; extensions cover routes, injection, events and transforms.

| [[field-apiVersion]] `apiVersion`

| [[field-hostAPI]] `hostAPI`
| string
| yes
| Host API constraint, for example >=1.0 <2.0 or *. Compared with the trust store coreVersion. Minimum length: 1.

| [[field-publisher]] `publisher`
| string
| no
| Optional publisher identity.

| [[field-keyId]] `keyId`
| string
| yes
| Signing key id; must exist in the trust store keys map. Minimum length: 1.

| [[field-artifact]] `artifact`
| <<config-artifact,object>>
| yes
| The signed artefact (binary, container or OCI reference). Its digest is verified before the plugin is trusted.

| [[field-dependencies]] `dependencies`

| no

| [[field-licenseFeature]] `licenseFeature`
| string
| no

| [[field-events]] `events`

| [[field-signature]] `signature`

|===
| Field | Type | Required | Description

| [[field-events-types]] `types`
| array of string (one of: `request`, `auth`, `error`, `billing`, `audit`)

| [[field-events-filters]] `filters`
| <<config-events-filters,object>>
| no

| [[field-events-maxLagBytes]] `maxLagBytes`
| integer
| no

| [[field-events-onMaxLag]] `onMaxLag`
| string (one of: `block`, `drop`)
| no
| Backpressure policy. block answers affected routes with 503 until the plugin catches up; drop advances the cursor to the lag limit and marks the plugin degraded.
