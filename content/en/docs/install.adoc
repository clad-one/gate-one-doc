= Components and installation

Gate One is one binary in front of your applications. Everything else —
an identity provider, the optional broker, the token broker, Redis — is a
separate component you choose to run. See
link:/docs/components/[Components] for a page per component.

== The components

[cols="1,2,2,1",options="header"]
|===
| Component | Role | Shipped as | Required?

| **Gate One** | The gateway: route policy, session, proxy, MCP, injection | Signed release binary `gate-one` | yes
| **Identity provider** | Identification and (optionally) authorization claims | External (Keycloak, Entra ID, Auth0, …) | yes
| **Reverse proxy** | TLS termination, routing, load balancing | External (Traefik, nginx, Caddy, …) | recommended
| **`cladone-auth`** | Optional embedded IAM / OIDC issuer (IdP federation, grants) | Signed release binary `cladone-auth` | optional
| **auth-bridge** | Reference implementation of the `http-bridge` contract | Source `services/auth-bridge` | optional
| **Token broker** | Per-user delegated credentials for upstream calls | Source `services/token-broker` | optional
| **Redis** | Shared session/revocation state for several replicas | External (Sentinel) | only for HA
|===

All releases attach a single `services_<version>_src.tar.gz` containing
the auth-bridge and token broker sources. They are **not** part of the
`gate-one` binary: each runs as its own container.

== Minimal install

Gate One + one OIDC provider + a TLS reverse proxy.

. **Download a release** (`gate-one_<version>_<os>_<arch>.tar.gz` from the
  release page or a signed `dist/`), verify it (see
  link:/docs/extending/publish-a-plugin/[Publish and trust a plugin] for
  the trust model), and extract it.
. **Write `api-routes.json`** — start from
  link:/docs/examples/direct-oidc/[Direct OIDC] or
  link:/docs/examples/keycloak-google/[Keycloak with Google].
. **Validate, then start**:
+
[source,bash]
----
export OIDC_CLIENT_SECRET=...        # the authProvider.clientSecretEnv variable
gate-one -check -config api-routes.json
gate-one -config api-routes.json      # listens on :3000
----
. **Put it behind the reverse proxy** — TLS, the public host, and the
  OIDC callback URL. See
  link:/docs/components/reverse-proxy/[Reverse proxy].
. **Probe it** — `/healthz` (liveness) and `/readyz` (readiness).

== Optional components

* link:/docs/components/cladone-auth/[cladone-auth (embedded IAM)] —
  configure it and point Gate One at it with `authProvider.type: "oidc"`.
* link:/docs/components/auth-bridge/[auth-bridge] — the reference
  implementation of the link:/docs/components/bridge-contract/[HTTP bridge
  contract], used with `authProvider.type: "http-bridge"`.
* link:/docs/components/token-broker/[Token broker] — the service behind
  link:/docs/features/delegated-credentials/[delegated credentials],
  declared in `tokenBroker`.
* link:/docs/components/redis/[Redis] — shared state required only for
  link:/docs/features/horizontal-scaling/[several replicas].

== What is not a component

* A **Backend-For-Frontend** is your application behind a `backend:`
  route, not a Gate One service (see
  link:/docs/extending/plugins/[Plugins]).
* **Keycloak**, **Postgres** and other platform services are yours to
  run; Gate One only needs an OIDC issuer (and Redis for HA).

== Runnable deployments

The source repository ships two prepared deployments:

* [`deploy/local/`](https://github.com/clad-one/gate-one/tree/main/deploy/local)
  — demos on `*.localhost`: no domain and no external account. Four run
  without Docker (embedded `dev` provider); four run the real OIDC chain
  with Docker Compose and a local demo identity provider. Every runnable
  [example](/docs/examples/) links its demo.
* [`deploy/vps/`](https://github.com/clad-one/gate-one/tree/main/deploy/vps)
  — the production shape: Traefik with Let's Encrypt, Gate One,
  `cladone-auth` and Google, ready to copy to a VPS.

Both mount prebuilt binaries from `$BIN_DIR`; neither builds Gate One.
Besides `gate-one` and `cladone-auth`, the demos use
`gate-one-demo-idp` — a fake OIDC provider shipped with each release and
never to be used in production.
