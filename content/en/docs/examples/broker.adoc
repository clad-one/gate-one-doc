= Broker federation

The optional broker (`cladone-auth`) federates several upstream identity
providers and re-emits its own Ed25519-signed tokens. Gate One trusts
only the broker.

== Files

* link:/examples/broker-multi-idp/broker.json[`examples/broker-multi-idp/broker.json`]
* link:/examples/broker-multi-idp/routes.json[`examples/broker-multi-idp/routes.json`]

== Broker configuration

[source,json]
----
{
  "publicUrl": "https://auth.example.com",
  "listen": ":8081",
  "redis": {
    "url": "redis://redis:6379/0",
    "passwordEnv": "REDIS_PASSWORD",
    "prefix": "cladone:broker:v1:",
    "authPrefix": "cladone:auth:v1:"
  },
  "tenants": [{
    "id": "mycompany",
    "clientId": "gate-one",
    "clientSecretEnv": "MYCOMPANY_BROKER_CLIENT_SECRET",
    "redirectUris": ["https://login.example.com/auth/callback"],
    "upstreams": {
      "google": {
        "issuer": "https://accounts.google.com",
        "clientIdEnv": "GOOGLE_CLIENT_ID",
        "clientSecretEnv": "GOOGLE_CLIENT_SECRET",
        "hostedDomain": "example.com"
      },
      "microsoft": {
        "issuer": "https://login.microsoftonline.com/common/v2.0",
        "clientIdEnv": "MICROSOFT_CLIENT_ID",
        "clientSecretEnv": "MICROSOFT_CLIENT_SECRET",
        "optional": true
      }
    },
    "defaultRoles": ["user"],
    "allowedDomains": ["example.com"]
  }]
}
----

== Gate One configuration

[source,json]
----
{
  "authProviders": [{
    "id": "mycompany",
    "type": "oidc",
    "issuer": "https://auth.example.com/t/mycompany",
    "clientId": "gate-one",
    "clientSecretEnv": "MYCOMPANY_OIDC_SECRET",
    "loginBaseUrl": "https://login.example.com",
    "cookieDomain": "example.com",
    "cookieName": "gate_one_mycompany_session",
    "roleClaims": ["roles"],
    "sessionKeyEnv": "MYCOMPANY_SESSION_KEY",
    "sessionStore": {
      "type": "redis",
      "url": "redis://redis:6379/0",
      "passwordEnv": "REDIS_PASSWORD",
      "prefix": "cladone:auth:v1:"
    }
  }],
  "defaultAuthProvider": "mycompany",
  "routes": [{
    "host": "app.example.com", "path": "/*", "frontend": true,
    "backend": "http://app:8080", "auth": { "provider": "mycompany" }
  }]
}
----

== Run it

[source,bash]
----
# broker
export REDIS_PASSWORD=...
export MYCOMPANY_BROKER_CLIENT_SECRET=...
export GOOGLE_CLIENT_ID=... GOOGLE_CLIENT_SECRET=...
export MICROSOFT_CLIENT_ID=... MICROSOFT_CLIENT_SECRET=...
cladone-auth -config broker.json

# gate one
export MYCOMPANY_OIDC_SECRET=...
export MYCOMPANY_SESSION_KEY="$(openssl rand -base64 32)"
gate-one -check -config routes.json
gate-one -config routes.json
----

`optional: true` on Microsoft means the upstream is skipped until both
environment variables exist; the broker still starts with Google only.

== What to look at

* the broker's identity-provider chooser (Google, Microsoft);
* the broker session cookie on `auth.example.com`, shared by all apps in
  the browser;
* `roleClaims: ["roles"]`: the broker emits roles, so
  `auth.identity.roles` works in Gate One;
* a global logout in one application: the broker revokes `sid` and `sub`,
  and Gate One refuses the session on the next request.

== Caveats

* The broker is an issuer, not a general authorization server. Route
  rules stay in Gate One.
* Upstream secrets are read from the environment; never put them in the
  JSON.
* The broker is optional. A single OIDC provider is simpler: use
  link:../multi-app-sso/[multi-app SSO].
