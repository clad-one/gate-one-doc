Gate One configuration

Generated from schemas/api-routes.schema.json by scripts/gen-config-docs. Do not edit this page: edit the schema or the generator.

The api-routes.json file consumed by the gate-one binary. Relative paths (certificates, keys, plugin artefacts, WAL directories) are resolved from the configuration file.

Fields

FieldTypeRequiredDescription

securityHeaders

object

no

Platform-wide response hardening, emitted by the gateway on EVERY response it serves (proxied or generated: health, stats, 401/403, MCP metadata, PWA assets, CSP collector). Declaring the block applies the secure defaults; each field can be tightened or disabled. Referrer-Policy is only set when the response does not already carry one (a proxified app’s stricter policy wins). Absent = nothing (an install whose edge proxy already sets them can opt out).

license

object

no

Optional offline signed licence (Ed25519), one token per period. Absent, invalid or expired = evaluation/personal mode: the gateway keeps serving; the user badge shows a notice. The private signing key NEVER ships (only publicKey is embedded).

authProvider

object

no

Authentication provider. dev is the embedded loopback-only IdP used for onboarding/tests; http-bridge is any external service implementing the Gate One HTTP bridge contract (auth-bridge is the reference implementation; a non-conforming service needs an adapter); oidc is the native Relying Party (discovery, code+PKCE, JWKS, session, logout, MCP resource server); jwt is a stateless bearer verifier. Absent = legacy oidc + auth-bridge translation, so existing configs are unchanged. The legacy type http is accepted as a deprecated alias of http-bridge.

authProviders

array of object

no

Named authentication providers for per-route binding. Mutually exclusive with the legacy singular authProvider. Each item uses the same fields as authProvider plus id/cookieName; a route selects one with auth.provider.

defaultAuthProvider

string

Provider id used by routes that do not set auth.provider. Required when more than one authProviders entry is declared.

defaultAppUrl

string

no

Global fallback for a bare visit to a login host root (302), preserving the query string. A provider’s own defaultAppUrl wins for its login host. Email verification/account links must carry a return target; use defaultAppUrl only as an operational fallback. Point it at a neutral page (e.g. your landing), not at one application.

tokenBroker

mcpSets

Named groups of MCP services exposed with their own access rights (resource/scope/identity) and per-member tool filters. A member endpoint is set.host + set.endpoint + member.path.

publisherFeed

object

no

Optional signed publisher feed: compatible Gate One versions, external components and plugins, with their revocation status. Loaded and verified at startup; the operator’s trust store stays authoritative. Absent = no feed is consulted.

turnstile

object

no

Platform-wide Cloudflare Turnstile bot check for form pages. Presence enables it (explicit enabled=false disables it in templated configs). The widget is injected into matching HTML pages and every matching request is verified against the Siteverify API BEFORE the backend: a missing/invalid token is answered 403 (readable page for a navigation, JSON otherwise), a Siteverify outage 503 (fail closed). The block is global on purpose: one place to change, no per-host duplication. LIMITATION: it protects only traffic that passes through this Gate One instance; a second ingress, an internal caller or a direct port reaching the application bypasses it. Network isolation (only Gate One can reach the application) remains required. The token is never logged nor written to usage events.

usage

object

no

Out-of-process usage-event bus (WAL + extension plugins). Presence enables it. Events are produced only for the subscribed types; a full durable share is answered with a targeted 503 (health/readyz/auth-probe exempt).

routes

array of object

Routes served by this gateway. Order is not significant: the most specific host/path match wins.

routes.csp

Content-Security-Policy emitted (or amended) by the gateway — the only component able to generate a per-response nonce and write it into the HTML it already rewrites (guard, PWA, custom injections). By default the origin’s policy is NEVER removed or weakened: the gateway’s policy is added as a SECOND header (browsers enforce all of them, so the effective rule is the strictest) and the hashes of the gateway’s own injected script and guard stylesheet are APPENDED to the origin’s script-src / style-src (script-src-elem > script-src > default-src, style-src-elem > style-src > default-src). Set own=true to remove the origin policy explicitly and let the gateway own it (opt-in, logged, requires mode nonce/hash and reportOnly=false). Applied to HTML responses only.

FieldTypeRequiredDescription

mode

string (one of: off, merge, hash, nonce)

yes

"off" = nothing (the origin’s policy passes as-is); "merge" = keep the origin policy and only add the hashes of the gateway’s injected scripts (no policy of our own); "hash" = emit our policy with those hashes, no body rewrite; "nonce" = emit our policy with a per-response nonce and stamp the HTML in STREAMING mode (O(1) memory, upstream forced to gzip so the body is plain text).

reportOnly

boolean

no

Emit Content-Security-Policy-Report-Only instead of the enforcing header (progressive rollout: violations are collected, nothing is blocked). Requires mode nonce or hash.

own

boolean

no

The gateway OWNS the policy: the origin’s enforced and report-only CSP headers are removed before ours is emitted. Opt-in and logged (never silent). Requires mode nonce or hash and reportOnly=false: removing the origin’s enforcing policy to replace it with a report-only one would remove protection without enforcing anything. Use only for a site you control/accept, with a complete policy.

reportTo

string

no

Local path served by the gateway collecting the violations (report-uri). Default: /__gate-one_csp/report. Bounded ring buffer (256 entries), 16 KiB body limit, 50 reports/second, never authenticated. Pattern: /[\s?#]*$.

stampScripts

string (one of: inline, all)

no

"inline" (default) = only <script> tags WITHOUT src receive the nonce (external scripts stay governed by the host allow-list); "all" = every <script> tag. Nonce mode only. A tag that already carries a nonce is never rewritten.

directives

object

no

Directive name → sources, as one string ("'self' https://x") or an array. The gateway appends the nonce (nonce mode) and the injected scripts' / guard stylesheet’s hashes to the effective script-src / style-src, and report-uri when reportTo is set. To let the guard’s nonce/hash pass, declare style-src (e.g. "'self'").
