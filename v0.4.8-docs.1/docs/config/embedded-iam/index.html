Embedded IAM configuration

Generated from schemas/embedded-iam.schema.json by scripts/gen-config-docs. Do not edit this page: edit the schema or the generator.

The optional cladone-auth embedded IAM configuration. Secrets are read from the environment; a *Env field names the variable.

Fields

FieldTypeRequiredDescription

publicUrl

string

yes

External origin of the IAM, without a trailing slash (for example https://auth.example.com).

listen

string

no

Default listen address for cmd/cladone-auth (for example :8081).

sessionCookieName

string

no

IAM SSO cookie shared by all applications in one browser. Default cladone_iam_sid.

tenants

array of object

yes

Isolated issuers. Each tenant has its own key, client, upstream identity providers and policy.

redis

object

no

Shared store for flows, codes, refresh tokens and the revocation keyspace read by Gate One. Absent = in-memory store, single instance and tests only.

smtp

object

no

Outbound mail relay for local-account verification emails.

FieldTypeRequiredDescription

yes

string

no

clientSecretEnv

string

no

Environment variable holding the Gate One client secret.

redirectUris

array of string

yes

Allowed Gate One callback URLs (https, or localhost for tests).

array of string

no

Allowed post-logout targets. List every application origin as https://app.example.com/* (the host Gate One sends as post_logout_redirect_uri). Empty falls back to redirectUris, which covers only the login host, so a logout from an application host would be refused.

audiences

array of string

no

Audiences allowed for access tokens. Empty = the tenant id.

google

object

no

Upstream OIDC identity provider configuration. The google key defaults to the Google issuer; other keys require issuer, clientId/Env and clientSecret/Env.

upstreams

map of object

no

Named OIDC upstreams (google, microsoft, …). The key is the idp authorize parameter and the chooser label.

keyFile

string

no

Active Ed25519 private key file (base64 raw seed). Empty = ephemeral key, tests/dev only. Mutually exclusive with keyFiles.

keyFiles

array of string

no

Published keys, oldest first, newest active. Used to rotate tokens without invalidating old ones.

defaultRoles

array of string

no

Roles granted to every authenticated user.

allowedDomains

Allowed upstream hosted/email domains. Empty = no restriction.

adminEmails

array of string

no

Email addresses granted the admin role.

groupRoles

Map an upstream group/claim value to IAM roles.

accessTokenTtlSeconds

ID token lifetime in seconds. Default 600. Minimum: 1.

integer

localAccounts

boolean

no

appOrigins

array of string

Environment variable gating POST /register (server-to-server registration).

mappings

array of object

no

Ordered mapping rules translating upstream claims into IAM roles/scopes/claims. Evaluated on every federated login; results are not persisted on the user. The legacy groupRoles block remains supported for the groups claim.

rules

array of object

no

when/then policy rules: test the incoming token’s claims (when) and grant rights (then), including derived roles (rolesFrom) and copied claims (copyClaims). Evaluated on every login; results are not persisted on the user.
